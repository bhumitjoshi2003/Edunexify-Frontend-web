How this works
  • One row = one period slot for one class (or class + section).
  • Any number of rows may share the exact same slot (same class/section/day/period) — including the same subject or the same teacher. The import never rejects a row for this; reviewing and correcting the schedule afterward is the admin's job.
  • Class and Section must be active and match existing records; Subject must be configured for the class; Teacher ID must be an active teacher.
  • Nothing is created until you upload — review the results after import and fix failed rows in a re-upload if needed.
